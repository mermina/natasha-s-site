# Прототипы сайта — демо от 26.09.2026

Два варианта, оба на английском, оба черновые. Открывать двойным щелчком в браузере.

- `option-a-one-site.html` — один сайт, обычная навигация: Books / Photography / Writing / About.
- `option-b-two-sides.html` — вход разделён пополам: слева фотография, справа литература.
  После выбора стороны сверху остаётся переключатель и ссылка «Entrance» обратно на вход.

## Откуда контент

- Тексты, книги, публикации — из `input/Natasha-CV-2026.pdf`.
- Портрет и обложки книг — из Google Drive (`NATASHA_S`), подключены ссылками
  `drive.google.com/thumbnail?id=...`. Если файл не открыт по ссылке, вместо обложки
  показывается типографская заглушка с названием книги.
- Фотографии — **временные**, подтянуты прямо с natashas.smugmug.com. Наташа их не отбирала.
  Это заглушка для демонстрации верстки, не финальная подборка.

## Обложки книг

Показаны лентой, зеркально фотоленте: обложка целиком, без обрезки, подпись снизу
(жанр, издатель, год, премия). Клик открывает обложку крупно поверх страницы, Esc закрывает.
Если обложка не загрузилась из Drive, на её месте типографская карточка с названием.

Варианты раскладки собраны отдельно в `books-layouts.html`, переключатель сверху:

1. **Rail** — одной строкой, прокрутка вбок, зеркало фотоленты.
2. **Staggered** — обложки разного размера и высоты, как книги на столе.
3. **Asymmetric, all large** — тоже без сетки, но все обложки крупные, каждая на своём месте.

В обоих прототипах сейчас стоит вариант 1. Поменять — один вызов в build.py.

Для него нужны 2–3 строки о каждой книге от Наташи.

## Что проверить при открытии

Если фотографии не загрузились (видны серые прямоугольники), значит SmugMug не отдаёт
картинки по прямой ссылке. Тогда нужно попросить у Наташи экспорт выбранных кадров и
положить их в папку `img/` рядом с html.
